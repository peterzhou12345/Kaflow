# Security Policy

## Supported versions

Security fixes are applied to the latest `main` branch and the latest published release.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Contact the repository owner privately through the contact method listed on the GitHub profile. Include the affected version, operating system, reproduction steps, and impact. Do not include passwords, tokens, private keys, complete production certificates, or message payloads.

Kaflow is a local single-user tool. Keep the loopback server private and never expose its startup URL or token through a reverse proxy.
